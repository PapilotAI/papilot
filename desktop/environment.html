Start with WSL + Ubuntu

Open PowerShell as administrator and run this command. Restart if prompted, then open Ubuntu to finish setup.

wsl --install -d Ubuntu

Papilot uses the Codex installed in this environment. Sign-in is checked when you open your workspace.
