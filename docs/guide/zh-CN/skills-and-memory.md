## 复用技能

在聊天输入框开头键入 `/`（或点击输入框旁的 **+** 菜单），即可套用常用修订指令而无需反复手打相同要求。你可以在技能后补充作用范围，例如 `仅限第 3 节` 或 `压缩到 8 页以内`。

### 内置技能一览

| 技能 | 作用 | 是否修改文件？ |
| --- | --- | --- |
| **Polish**（润色） | 在不改变技术含义的前提下提升表达清晰度与学术流畅度 | 是（工作树） |
| **Proofread**（校对） | 修复语法、拼写、标点与排版笔误 | 是（工作树） |
| **Shorten**（精简） | 压缩冗余篇幅以满足页数或栏宽限制，同时保留核心论点 | 是（工作树） |
| **Check math**（公式核查） | 检查推导步骤、记号一致性与证明逻辑 | 是（工作树） |
| **Consistency**（一致性） | 统一全文术语、符号、大小写与交叉引用 | 是（工作树） |
| **Fix LaTeX warnings** | 处理溢出黑框、失效引用与编译警告 | 是（工作树） |
| **Address reviewers** | 结合粘贴或上传的审稿意见规划并落地修改 | 是（工作树） |
| **AI review**（`/ai-review`） | 在 **AI suggestions** 中生成锚定到具体行号的审稿建议 | **否**（只读） |

### 自定义技能

在 **Settings → Skills** 中创建、编辑或删除自定义技能：

- **全局技能**：存放在 `~/.papilot/skills/`，对你打开的每篇论文生效。
- **当前论文技能**：存放在 `<paper>/.papilot/skills/`，适合记录特定会议检查表或团队写作约定。

## 写作记忆

在 **Settings → Memory** 中保存长期写作偏好（如语气、术语规范、结论措辞强度、LaTeX 宏约定或标题大小写），后续所有编辑任务、`/ai-review` 审稿和协作模式工作智能体都会自动遵守：

| 作用域 | 文件路径 | 生效范围 |
| --- | --- | --- |
| **当前论文（仅本机）** | `<paper>/.papilot/memory.local.md` | 仅当前工作副本（自动写入 `.git/info/exclude`，不会被 Git 追踪）。 |
| **与合作者共享** | `<paper>/.papilot/memory.md` | 提交进 Git 后对所有仓库成员生效（Overleaf 同步会跳过此文件）。 |
| **所有论文** | `~/.papilot/memory.md` | 对你打开的每篇论文生效（可用 `PAPILOT_MEMORY` 指定其他路径）。 |

### 从审阅与对话中持续学习

- **从审阅中自动提炼**：完成一轮审阅后，Papilot 可在后台以轻量只读回合分析你反复修正的偏好，并在保存栏下方给出建议；只有你点击 **Remember**（支持 **Undo**）后才会真正写入。随时可在 **Settings → Memory** 中关闭学习或设置 **Memory language**。
- **在对话中直接吩咐**：直接告诉智能体记住、改写或遗忘某条偏好，智能体会通过内置记忆工具更新对应 Markdown 列表。你当次的明确要求和 PDF 批注始终优先于已保存的记忆。

## 文件与图片附件

通过 **+ → Add files…**、直接拖拽文件到输入框，或粘贴剪贴板图片来附加参考材料：

- **单条消息上限**：最多 **10 个文件**、单文件上限 **25 MB**、PNG/JPEG/GIF/WebP 图片单张上限 **5 MB**、单条消息总计上限 **100 MB**。
- **智能体如何读取**：Codex、Claude、Papilot Writer、Kimi 及其他支持视觉模型的智能体会接收原生图片输入（DeepSeek Harness 仅支持纯文本）。其余文件保存在原稿目录外并以本地路径提供给智能体读取，方便其查阅审稿 PDF、实验数据表，或按你的指示把新插图复制进任务工作树参与审阅。
