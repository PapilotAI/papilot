Reviewing the PDF审阅 PDF

The AI edits the source, and each change is reviewed on the typeset page.AI 改源码，改动排好版后在页面上逐条审阅。

01Annotate批注

Point at What Should Change在页面上指出要改什么

Select a sentence, or box an equation or a figure, and write what should change. The agent gets the exact source lines, with no need to know which file they are in.选中一句话，或框出一个公式、一张图，写下修改意见。智能体拿到的是对应的源码位置，不需要知道它在哪个文件里。

02Review审阅

Every Change, Decided One by One每一处改动，逐条拍板

A paper is written to be read, so every change has to be right. However many there are, each one is shown typeset, and nothing that hasn't been accepted reaches the paper. If one isn't right yet, comment on it and the agent revises it.文档是写给人读的，每一处都得准确。改动再多，也一条条排好版过目，没接受的不会进入文档。还不满意的，写条评论让它再改一轮。

03Commit提交

Every Change on the Record每一处改动都有记录

Each task runs in its own Git worktree, and committing and pushing accepted changes is a separate step. Every change to the paper stays in its Git history.每个任务都在独立的 Git 工作树里进行，接受之后，提交和推送是单独的一步。文档的每一次变化都留在 Git 历史里。
