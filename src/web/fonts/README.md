# Fonts

- TeX Gyre Pagella X (Regular, Bold, Italic) from the newpx bundle, under the GUST Font License (`GUST-FONT-LICENSE.txt`). The review engine uses the same faces.
- Inconsolata zi4 Regular, under the SIL Open Font License (`OFL-Inconsolata.txt`).

They match the LaTeX manuscript typography (Pagella text, Inconsolata code).
